## 기록 규칙

1. **트러블슈팅 위주로 쓴다.** 작업 나열이 아니라 "어떤 증상이었고, 무엇으로 원인을 좁혔고, 무엇으로 판정했나".
2. **실험 코드를 지우지 않는다.** 본 서버에 올리기 전 돌린 코드는 노트북에 그대로 남긴다.
3. **예측을 먼저 적는다.** 측정 전에 기대값을 쓰고, 틀리면 틀린 채로 남긴다 (9월 기록의 s8·rising 항목).
4. **수치는 실측만.** 추정은 "추정"이라고 쓴다.
